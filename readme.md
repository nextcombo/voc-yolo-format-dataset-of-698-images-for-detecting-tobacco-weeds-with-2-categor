# VOC+YOLO format dataset of 698 images for detecting tobacco weeds with 2 categories

Dataset format: Pascal VOC format + YOLO format (txt file without split path, only containing jpg images and corresponding VOC format xml files and yolo format txt files)

Number of images (number of jpg files): 6998

Number of annotations (number of xml files): 6998

Number of annotations (number of txt files): 6998

Labeling category count: 2

Label category names (note that the order of yolo format categories does not correspond to this, but is based on the labels folder's classes.txt): ["crop", "weed"]

Number of boxes labeled in each category:

Crop box count = 8042

Number of weed frames = 5019

Total frame count: 13061

Using labelImg:

Annotation rules: Draw a rectangle around the category.

Important Notice: No

Special : This dataset does not guarantee the accuracy or precision of the trained models or weight files. The dataset is provided with accurate and reasonable annotations only.
